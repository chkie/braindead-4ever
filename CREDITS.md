## Data sources

Data from these projects starts as unconfirmed and is replaced as soon as our own in-game measurements cover it.

| Source | Licence | What Braindead Forever uses |
| --- | --- | --- |
| [All The Things](https://github.com/ATTWoWAddon/AllTheThings) (Forever database) | MIT | quest IDs, givers, coordinates, prerequisites, races, classes, required level |
| [EG Link](https://github.com/JIVESCORP/eg-link-output-wowf) output for WoW: Forever, data from [Efficient Games](https://efficient.games) | CC BY 4.0 | measured giver and turn-in positions, faction, quest level, minimum level, race mask, start positions |
| [Polestar forever-db](https://github.com/fitzforge/polestar/tree/next/forever-db) | GPL-3.0-only | quests, levels, races and classes, givers, turn-ins, prerequisites, objectives, spawn points, map frames |

Polestar forever-db credits further projects whose values it carries: EG Link (CC BY 4.0), CMaNGOS classic-db (GPL-3.0), VMaNGOS values through pfQuest and Factoruide data (GPL-2.0-or-later), ForeverTDB (GPL-2.0), QuestieDB (Questie team), World of Warcraft: Forever client tables and pfQuest (MIT). The route data that contains Polestar values is GPL-3.0-only.

## Libraries

Braindead Forever embeds no libraries. When [TomTom](https://www.curseforge.com/wow/addons/tomtom) is installed, Braindead Forever hands it the current goal; TomTom is not part of Braindead Forever.
